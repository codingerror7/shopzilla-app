🛒 ShopZilla – Modern E-Commerce Web App

https://shopzilla-ecommerce-9anv.onrender.com

ShopZilla is a full-stack eCommerce web application built using the MERN stack.
It provides a smooth, modern shopping experience with secure authentication, product management, cart functionality, and order processing.

🚀 Features

👤 User Features

User Authentication (Signup / Login / Logout)
Browse Products
Search & Filter Products
Add to Cart
Update / Remove Cart Items
Secure Checkout
Order History
Responsive Design (Mobile + Desktop)

🛠️ Admin Features

Add / Update / Delete Products
Manage Orders
Manage Users
